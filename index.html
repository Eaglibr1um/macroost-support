MacRoost Support

A daily workspace for notes and tasks on Mac and iPhone.

Developer: Jax
Contact: liaojianxiang@gmail.com

Getting started

On Mac, Edit mode (Command-1) lets you write freely. Use # headings to group work. Task mode (Command-2) shows task cards. Presentation mode (Command-3) focuses on individual tasks. Open the logo menu for search, statistics, settings and recovery.

On iPhone, switch between Tasks, Notes and Search. Use the date controls for another day, the plus button to add a task, and a task’s status menu to mark progress. The iPhone version has fewer features than the Mac version; it does not include presentation mode, text replacement, media rendering or external AI connections.

iCloud sync and history

Enable iCloud Sync separately on each device using the same Apple account. Daily note text and task status sync; attachments, preferences and recovery files stay local. Notes remain available offline. If devices edit the same day separately, review and combine the retained drafts in iCloud Sync.

Turning sync off keeps copies. Cloud history can be kept until you remove it, or cleaned after 7, 30 or 90 days. Cleanup always keeps current notes, unresolved drafts and at least 20 recent versions per day. Small records of removed versions remain to prevent old offline copies from restoring deleted draft text. Local recovery files are separate.

Remove All iCloud Notes & History deletes the cloud notes and draft history after confirmation. Current notes and recovery files on your devices remain. Other devices pause sync when they reconnect. A small library-removal record remains to prevent automatic re-upload. Creating a new library uploads this device’s current notes; older libraries remain paused. Export important notes from every device first.

If sync pauses because the Apple account or library changed, export and review local notes before reconnecting. MacRoost does not automatically transfer a previous account’s notes into another account.

Backups and export

On Mac, Export Notes & Backups copies daily notes, recovery snapshots, imported media and text replacements. A completed export includes EXPORT-COMPLETE.txt. Restore a Note preserves the current note before restoring a previous file. The iPhone version exports the selected daily note. Keep independent backups outside the app and iCloud library.

Mac window controls

Drag empty space beside the date to move the main window. Resize using its edges. Command-W hides it; the menu-bar icon or configured shortcut shows it. Option-S is the default shortcut. Launch at login may require approval in macOS System Settings.

AI features on Mac

Available on supported builds and devices. Built-in summaries use Apple’s on-device model when available. External AI access is off by default, uses a separate key for each client and defaults to read-only. Edits need app-side approval. A connected cloud AI service may send note content to its provider under that provider’s policies.

Report a problem

Open a support email draft. Include your app version, system version, what you did and what you expected. A screenshot can help. Do not send confidential notes. Nothing is emailed or uploaded automatically.
